Implementation of own atoi function and own atof function

1. my_atoi :

The my_atoi function converts an ASCII string into a 32-bit signed integer by systematically sanitizing the input stream before executing arithmetic accumulation. It begins by scanning and skipping all leading whitespace characters, including standard spaces, horizontal tabs, newlines, carriage returns, form feeds, and vertical tabs. Once the first non-whitespace character is reached, the parser checks for an explicit sign prefix, recording a negative polarity if a minus sign is found or defaulting to positive otherwise. The routine then traverses contiguous numeric characters from '0' through '9', subtracting the ASCII offset '0' and iteratively shifting the running accumulator using base-10 arithmetic (res = res * 10 + digit). To prevent undefined overflow or underflow behavior, the accumulator is continuously checked against standard 32-bit limits: exceeding positive bounds triggers an immediate return of INT_MAX (2147483647), while exceeding negative bounds returns INT_MIN (-2147483648). The evaluation terminates immediately upon encountering the first non-numeric character or null terminator, after which the calculated magnitude is multiplied by the determined sign and safely returned as an integer. 


2.my_atof :

The my_atof function converts a numeric string into a double-precision floating-point value using a sequential, two-phase accumulation architecture. It first eliminates any preceding whitespace characters such as spaces, tabs, and line breaks, and subsequently evaluates the initial character to determine whether a positive or negative sign is applied. The algorithm then processes the whole-number portion by converting contiguous digits into their base-10 integer representation until a non-digit character or a decimal point (.) is encountered. Upon detecting a decimal point, the parser transitions to the fractional phase, continuing to accumulate following digits into the numeric register while simultaneously multiplying an independent scaling divisor (power, initialized to 1.0) by 10.0 for each decimal position processed. The parsing loop terminates safely upon encountering any secondary decimal point, non-digit symbol, or delimiter, preserving valid numeric data up to the anomaly. Finally, the accumulated value is divided by the computed power scale factor to restore proper fractional magnitude, multiplied by the extracted sign, and returned as a standard double
